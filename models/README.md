# PLA 単ノズル用 CylinderTag 試験片

`cylindertag_d30.stl` を Bambu Studio に読み込む。単位 mm。

2026-10-18修正: 初版は画像のY軸とCADのY軸の違いにより模様が鏡像になっていた。
現在の生成器はY方向を反転して修正済み。印刷済みの初版は、改善した検出器が
`mirrored=true` として照合するため、今回の認識検証のための再印刷は不要。

- 円筒直径の目安: 30 mm。既存辞書 `CTag_2f12c.marker` の **ID 0**（先頭の符号列）。
- 全体: 約 **94.876 × 44 × 0.4 mm**。マーカー高さ40 mm、上下の白余白各2 mm。
- 白い下地: Z=0〜0.2 mm。黒い模様: Z=0.2〜0.4 mm。
- 平面XYに寝かせて印刷。底面Z=0。倍率100%、サポート・ラフトなし。
- **初層高さも通常層高さも0.20 mm**、可変レイヤー高さは無効。
- 白 PLA Basic で1層目を印刷し、**2層目（Z上面0.40 mm）の印刷開始前**に一時停止。
  手動で黒 PLA Basic に交換して、白が混じらなくなるまで排出後、再開する。
- STLに色や一時停止設定は入らない。スライス後のプレビューで、1層目は白下地全面、
  2層目は24個の黒い台形だけになっていることと、停止位置を確認する。
  AMS用の色割り当てだけに頼らず「一時停止」を入れる。機種は実機に一致するプロファイルを選ぶ。
- 自動の象足補正などで細い模様が変わり得る。寸法精度を比べる際は設定も記録する。

## 巻き付けと精度の検証

幅は白下地の中央面を仮の中立面とし `π × (30 + 0.2)` で計算している。
曲げたPLAの実形状を保証する補正ではない。まず小さな曲げ試験を行い、割れや白化を確認する。
継ぎ目は重ねず、模様にかからない上下の白余白で固定する。接着層の厚み、継ぎ目の隙間、
PLAの浮き・伸び・曲げ半径によって実際のマーカー座標は変わる。

1. 最初は ID 0 が各方向から認識されるかを確認する。
2. 位置・角度の精度評価には、使用カメラのキャリブレーションと、巻き付けた実物に対応する
   `.model` が必要。付属の `CTag_2f12c.model` はこの試験片の座標ではないので流用しない。
3. 距離と角度の基準を別途用意し、複数の距離・回転角で誤差と静止時のばらつきを測る。
   紙印刷の同一模様も比較すると、積層痕・段差・光沢による影響を切り分けやすい。

このSTL自体は精度検証を完了したものではない。認識・製作条件の予備検証用。

## CAD brief / 再生成

単一の連結した閉じたソリッド。原点は底面の左下、XYが印刷面、+Zが厚み。
マーカーの台形は元の MATLAB `draw()` と同じdecoder・白幅比から連続座標で生成する。
Pythonソースの名前付き定数を変更すれば、円筒径・高さ・厚みを変更できる。
主要な検証項目は境界寸法、ソリッド数、形状妥当性、解析体積との一致、STLの閉鎖性。

Python 3.12以上、build123d、cadpy（CADスキル付属）、trimeshを使用。
プロジェクトルートから:

```bash
uv venv --python 3.12 .venv-cad
uv pip install --python .venv-cad/bin/python -r models/requirements-cad.txt /home/somak/.agents/skills/cad/scripts/packages/cadpy
.venv-cad/bin/python /home/somak/.agents/skills/cad/scripts/step models/cylindertag_d30.py --stl cylindertag_d30.stl
.venv-cad/bin/python models/cylindertag_d30.py
```

STEP/STL/SVGと隠しビューア用データは再生成可能な出力。
SVGは上から見た白黒の参照画像で、STLに色を付ける設定ファイルではない。

生成時の検証: STEPは有効な1ソリッドで、境界寸法94.876098 × 44 × 0.4 mm、
台形面積から求めた解析体積と一致。STLは閉じた1連結成分、面の向きが整合し396三角形。
Z=0.1 mmの断面は1輪郭、Z=0.3 mmは24輪郭。実機でのスライス・印刷・認識は未検証。

一時停止操作の参考: [Bambu Studio公式リポジトリの関連issue](https://github.com/bambulab/BambuStudio/issues/2512)。
